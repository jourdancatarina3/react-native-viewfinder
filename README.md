# react-native-viewfinder

Buttery-smooth pinch-to-zoom images and a full-screen gallery for React Native. Zero native code.

## Installation


```sh
npm install react-native-viewfinder
```


## Usage


```js
import { multiply } from 'react-native-viewfinder';

// ...

const result = multiply(3, 7);
```
